# Homeless Team Website

The official website of Homeless Team.

## Features

- Modern responsive design
- Markdown-powered blog system
- Copyright Center
- Multi-language support
- Static website
- GitHub Pages compatible

## Structure

```
blog/
copyright/
assets/
index.html
```

## Local Development

Simply open `index.html` in your browser or use a local web server.

## Deployment

This website is designed to work with GitHub Pages without any build tools.
